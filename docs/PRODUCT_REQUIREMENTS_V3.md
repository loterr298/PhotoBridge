# PhotoBridge V3 用户要求

1. 用户只执行一个动作：点击“导入到 iPhone”。
2. 第一张资源发送完成后立即写入 iPhone 系统“照片”，随后按 Mac 当前顺序继续下一张。
3. PhotoBridge 收件目录只做传输中转，不能作为用户完成结果。
4. 扫描、发送、资源检查、PhotoKit 写入和回读合并成一条总进度。用户界面不显示“核对发送结果”“预检”“恢复”等内部步骤。
5. 只有 PhotoKit 写入并回读确认完成后，Mac 才显示 100% 和“已完成”。
6. 断线或暂停后从最后一个已写入系统相册的位置继续，不能重新扫描整个来源文件夹，也不能重复创建照片。
7. 顺序以 Mac 显示的文件顺序为准。原文件名和原始资源内容保持不变。
8. 原图内部 EXIF 和私人相机元数据不修改。系统编辑记录时间变化必须单独记录。

V3 的验收门槛是新版 iPhone 和新版 Mac 同时安装，且至少有一次真机 PhotoKit 写入和回读记录。模拟器、单元测试和收件目录文件存在不能替代该真机证据。
